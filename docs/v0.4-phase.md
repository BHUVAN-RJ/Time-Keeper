## 4. Env / ops notes

- **Turso:** migrations must run against remote DB (`drizzle.config.ts` uses `TURSO_*`). Missing columns (e.g. `tags_enabled`) cause runtime query failures on `/today`.
- **Tags:** optional; user can disable in Settings → Tags without deleting existing tag data.
- **Body doubling:** only prompts when Deep work block has `stated_intent` and interval > 0 in Settings.
