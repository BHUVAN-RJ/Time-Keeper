## 2. Google Calendar — as built and why

### Product choices (user-driven)

1. **Separate OAuth from Auth.js sign-in** — “Connect Google Calendar” in Settings uses its own OAuth flow (`/api/google-calendar/connect` → callback). Magic-link login stays on Resend; calendar tokens are not mixed with session provider tokens.
2. **Multiple Google accounts** — table `google_calendar_accounts` (unique per `user_id` + `google_email`). User can connect personal + `.edu` and disconnect per account.
3. **All calendars on each account** — no per-calendar checkbox in v0.2. Simpler for solo use; edu noise handled by title filters (below).
4. **Read-only everywhere** — scope `calendar.readonly` only; no event creation from Time Keeper.
5. **Surfaces:** Week (this week + next week sections), Today calendar peek, AM rundown today/tomorrow peek.
6. **15-minute cache + poll while app open** — `CALENDAR_CACHE_TTL_MS` in `src/lib/google-calendar/config.ts`; `CalendarPollProvider` in app layout refreshes when accounts exist. On API failure, **stale cache is shown** with a warning banner (`CalendarStaleBanner`).
7. **Title filters for academic noise** — built-in regexes (office hours, OH, drop-in, TA office, etc.) in `src/lib/google-calendar/filters.ts`; user can add lines in Settings (`user_preferences.calendar_exclude_patterns`). Filters apply on fetch and cache read; saving custom patterns clears cache. **Why post-fetch:** Google Calendar API cannot exclude by title in the query; filtering client-side keeps one code path for Week, Today, and AM rundown.

### Technical layout

| Piece | Path |
|-------|------|
| OAuth connect/callback | `src/app/api/google-calendar/` |
| Server actions | `src/actions/google-calendar.ts` |
| Fetch + merge + cache | `src/lib/google-calendar/service.ts` |
| Token encryption (AES-256-GCM) | `src/lib/token-crypto.ts` |
| Settings UI | `src/components/google-calendar-settings.tsx` |
| Migrations | `0004_google_calendar.sql`, `0005_calendar_exclude_prefs.sql` |

### Env (server)

```env
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GOOGLE_TOKEN_ENCRYPTION_KEY=   # openssl rand -base64 32
AUTH_URL=http://localhost:3000 # must match Google Cloud redirect URI host
```

**Redirect URI (Google Cloud Console):** `{AUTH_URL}/api/google-calendar/callback`  
Must match `googleRedirectUri()` — pass `redirectUri` from server into Settings UI to avoid hydration mismatch with `window.location.origin`.
